Quick Hits — Fri Oct 23, 2026

2026-10-23

Friday theme: proofs and permissions. The interesting work this week is about letting agents do more while being able to show exactly what they can't do. Ten items, no deep dive.

1. Anthropic: LLMs make formal verification practical at scale

Anthropic's Frontier Red Team, working with Theorem, had Claude prove security properties for 123 real open-source libraries at the RISC-V assembly level: the programs always exit normally without memory-safety errors or failed assertions, for every input under 64 MB and every modeled Linux OS response and memory layout (assuming a single-threaded static binary with a fixed memory budget). Along the way Claude found bugs that had survived years of testing. They're publishing a subset of the proofs plus the RISC-V and OS semantics, Theorem is offering to run the pipeline on other open-source projects, and there's a Claude skill for verifying your own code. The post also covers zlib, proving a Rust-written Python interpreter behaves the same as the original, and its limitations. Anthropic · HN

Why it matters to you: "proven not to crash on any input" is a very different sales pitch than "we added tests." If you have a client with a parser, codec, or protocol handler in C or Rust, try the Theorem skill on one small module and see what it costs.

2. Chinese hackers used AI agents to breach ~2,250 orgs via ConnectWise

Microsoft researchers say China state-aligned attackers broke into ConnectWise's cloud backup service and stole the app credentials it uses to connect to customers' Microsoft-hosted environments, then logged in as an authorized app to read email and files. Using ARTEX, an open-source AI framework for stress-testing defenses, they hit about 2,250 organizations at almost 3,000 attempted sign-ins per minute. ConnectWise has paused the backup service and is working on restoring it. TechCrunch

Why it matters to you: it's the same pattern as LiteLLM, Railway, and OpenCode this week: go after wherever credentials pile up. If a client uses ConnectWise backup, review and rotate its Microsoft 365 app grants today. Also, audit third-party OAuth apps with broad mail access as a standard part of your security work.

3. 1Password for Agents: agents log in without seeing the password

When an agent tries to sign in for you, it presents a unique key to 1Password, you get an alert to approve it, and 1Password fills the credentials itself. Launch partners include Claude Duet, OpenAI's Dots and ChatGPT Work, Grok Bot, Meta's Muse, and Town. TechCrunch notes that Axios reports banks are now detecting agent activity inside customer accounts. TechCrunch · 1Password

Why it matters to you: "where do the agent's credentials live?" is the first question a careful client asks. Approve-per-login with nothing stored in the agent is a clean answer to put in proposals.

4. OpenAI's Decisions API is now generally available

OpenAI's answer to TypeSafe's Jev "decision model" picks among a set of options and returns a confidence rating, in about 100 to 180 ms instead of one to three seconds. For now it's ChatGPT Luna reconfigured for speed and cost, not a specially trained model. The GA version adds voice and visual inputs and region-targeted inference. Speak says time between actions dropped from 1.4 s to 0.13 s; Box, Datadog, and Ramp were early testers. TechCrunch · OpenAI

Why it matters to you: lots of agent pipelines spend a full LLM call on what's really a routing or classification step. Swap one of those out and measure the latency and cost difference. It's an easy win to show a client.

5. Anthropic donates Agent Skills to the Agentic AI Foundation

The Agent Skills standard now lives with the Linux Foundation's Agentic AI Foundation (co-founded by Anthropic, Block, and OpenAI), which already hosts MCP. Anthropic says the aim is to keep skills open, community-driven, and vendor-neutral. Anthropic · Simon Willison

Why it matters to you: skills you write for one client's Claude setup are more likely to carry over to other agents. That makes a library of reusable skills a better asset for your agency.

6. NVIDIA OpenShell 0.1: a policy runtime for fleets of agents

OpenShell (Apache 2.0, about 18k stars) runs each agent in a sandbox where kernel controls limit files and system calls, and every network connection gets a policy check before it leaves. Agents never see real credentials; OpenShell adds them only to requests going to approved endpoints. Before a policy change is applied, it uses formal verification to flag new risky access, like reaching a new host with credentials, so a human reviews it. The 0.1.x line adds a stable release cadence, new isolation primitives, and new APIs. GitHub · docs · HN

Why it matters to you: injecting credentials at the network edge is the right model for client agent deployments. Worth an afternoon to see if it fits as your default self-hosted agent sandbox.

7. Claude Code 2.1.309 closes a batch of sandbox and permission gaps

Fixes include sandboxed Bash running the shell's startup files outside the sandbox before each command, macOS denyWrite globs missing paths reached through symlinks, sandboxed commands being able to modify the --mcp-config file, an Edit(path) deny rule not blocking some Bash redirects to that path, and worktree isolation accepting some locale-prefixed and zsh arithmetic commands it should refuse. GitHub release

Why it matters to you: if you count on the sandbox or deny rules for unattended runs, update now. The startup-file fix alone is worth it.

8. Codex CLI 0.164: presets, inline model switches, credential masking

New: ten numbered /presets slots for saved prompts and slash commands, inline arguments for /model and /permissions (model, reasoning effort, speed, permission profile), masking of credentials in supported remote Bash and zsh snapshot sessions, enterprise MCP auth (including OAuth clients that need secrets), and the Bedrock setup wizard on by default. Failed compaction no longer leaves partial summaries in history. GitHub release

Why it matters to you: presets are a cheap way to make your best prompts like "review this diff" or "write the migration plan" one keystroke for everyone on a client team.

9. Copilot usage metrics now name your custom skills, agents, and MCP servers

Org and enterprise usage reports now show the configured names of customer-defined skills, custom agents, MCP servers, slash commands, and plugins instead of lumping them under "other" or "custom," and each list holds up to 25 entries instead of five. GitHub

Why it matters to you: if you build internal skills or MCP servers for a Copilot shop, you can now show which ones get used. That's the adoption data that gets the next engagement approved.

10. eMudhra is leaving the public TLS certificate business

Following Tuesday's revocation of eight intermediates over weak keys, eMudhra's board voted to withdraw from global SSL/TLS. The company says it revoked the affected CAs within 14 hours, no end-entity certificates were issued from them, and TLS is about 1% of revenue. eMudhra · HN

Why it matters to you: if any client still has eMudhra certificates, plan the move to another CA now instead of waiting for browsers to decide.
