1. Firecracker VM escape: guest-to-host root, demonstrated end to end

PWN Research's "PwnEscape Part 2" (top of HN, ~250 points) takes the host-memory primitive from Part 1 and turns it into code execution in the Firecracker VMM process. From inside the guest they locate their own page in host memory via EPT walks, recover Firecracker's page tables and ASLR base, find the live vCPU thread's saved registers while it sits in KVM_RUN, and redirect its return into a call of their choosing, then restore state so the VM keeps running. Target: Firecracker v1.16.1 on x86-64, host kernel 7.0.0-1011-aws. Big caveat they state themselves: Firecracker ran directly as root with no jailer, so the call ran as root on the host; a jailed deployment (dropped privileges, namespaces, seccomp) needs its own assessment. PWN write-up · HN

Why it matters to you: lots of coding-agent platforms (and probably some of your clients' DIY setups) treat "it's in a microVM" as the security boundary. Audit that the jailer, seccomp, and a non-root VMM user are actually on, keep host kernels patched, and don't co-locate high-value secrets on sandbox hosts. "Sandbox hardening review" is a very sellable one-week engagement right now.

2. Claude Enterprise inference hooks are GA: your server says allow or deny

Anthropic shipped a Claude Enterprise security bundle (Nov 5). The headline is inference hooks, now generally available: prompt hooks send each governed request to an HTTPS security server you (or your DLP vendor) run before inference starts, and pre-tool-call hooks check tool calls before they execute, including calls from skills, plugins, and connectors. It runs on Anthropic's side, so one config covers claude.ai, Claude Code, Cowork, Chrome, Slack and more with nothing on laptops. Not available on Bedrock or Vertex; system prompts and tool definitions aren't sent; voice mode has gaps. Also new: a security center (beta) that diffs your settings against Anthropic's recommended config, centralized admin at admin.claude.com, and a toggle to block personal Claude accounts on managed machines. Anthropic · Inference hooks docs

Why it matters to you: this is a real product slot for your agency. "We'll build and host your AI security server" (PII redaction checks, secret detection, transcript archival, tool-call policy) is concrete, recurring work for regulated clients. Read the docs on fail-open vs fail-closed behavior before you promise anything.

3. GitHub's new Git storage: built for 5,000 agents on one repo

GitHub's engineering post on "Project Rubicon" explains the storage architecture announced at Universe. Key insight: Git objects are immutable and content-addressed, so only reference updates need agreement. Packs go to Azure Blob Storage; refs and the pack manifest live in a dedicated quorum-replicated compare-and-swap log ("Ref-CAS") that locks only the refs a push touches. Disposable "virtual replicas" serve reads and writes from a rebuildable cache, and separate compaction nodes merge packs in the background. Internal tests: 5,000 concurrent agents and 7,200 pushes/sec to one repo with flat read latency. Limited private preview now, broader rollout early next year. Coming soon: clone-free file access, an atomic multi-file commit API, and event streams. GitHub Blog · HN

Why it matters to you: the roadmap items are the practical bit. An atomic commit API and server-side file reads mean agents that never clone, which cuts sandbox cost and setup time. Design client agent pipelines so they can switch to that when it ships.

4. Hightouch: cheap judge first, Opus only when it's unsure, ~4× cheaper

Hightouch tested LLM judges for spotting over-merged identity-resolution profiles (one "person" that's really two). Cheap decision models (Jev, GPT-6 Luna's Decisions API) returned a 0–1 confidence at $0.05–$0.10 per 1,000 identities in ~0.15s, versus Opus 5.5 at 99.0% accuracy and $3.86. The trick: Jev's confidence is well calibrated, so you send only its unsure band (30–90%) to Opus. That got 98.8% at $0.88 on the easy set, and on the hard set it actually edged Opus alone (95.3% vs 95.1%) at $2.94 vs $5.39, because it automatically escalates more when cases get harder. Luna scored higher on its own but was confidently wrong, so the hybrid helped it much less (91.6% on the hard set). Hightouch · HN

Why it matters to you: this is a reusable pattern for any client classification or review workload. Pick the cheap model for calibration, not raw accuracy, and escalate by confidence band. It's an easy way to show a client a 2–4× cost cut on an existing LLM pipeline.

5. Anthropic on agent memory: let the model judge salience, then "dream"

Anthropic's engineering post (Nov 6) on how Claude's memory works. Findings worth stealing: tell strong models what memory is for, not how to use it (a rigid "record only failures" rule cut Opus 5's gains); keep the always-loaded layer small (Claude Code loads only the first 200 lines / 25 KB of MEMORY.md as an index); and run offline "dreaming" passes that check notes against transcripts to fix mistakes and build linked wikis. On a ~420M-token internal corpus, wiki plus search scored 61% vs 53% for search alone and saved ~20K tokens per question. Multi-document merger questions hit 87% with the wiki vs 73% with search. One gotcha: several agents writing one shared table lost facts (41/57); one agent per contract quoting terms word for word got 57/57. Anthropic · HN

Why it matters to you: if you build knowledge agents for clients, a scheduled consolidation job over transcripts is a cheap, concrete upgrade. Give each source document its own page with a single writer to avoid concurrent agents overwriting each other.

6. Amp Spaces: one agent that manages your other agents

Amp launched Spaces (Nov 6): a conversation with a single agent whose job is to spawn and coordinate agent threads for you, shown as live task cards with status and "needs human" flags. Teammates share a space, comment, and tag @amp when they want it to act. Amp's examples: building Spaces inside a space, running a feature launch end to end (rollout, monitoring X/Slack/bug reports, fixes, refunds), and a recurring security review that split the codebase into 16 areas with a separate thread verifying each finding. Amp

Why it matters to you: the "find issues in one thread, verify each in another" security review is a pattern you can copy in any harness today. Spaces also signals that the interface is moving from managing sessions to managing an agent that manages them.

8. Harness changelog: Claude Code 2.1.319, Codex CLI 0.167

Claude Code 2.1.319 (Nov 6): MCP tasks can run in the background, a new permissions.denyInsteadOfPrompting setting denies instead of waiting on a prompt (handy for unattended runs), and a /claude-api latency-optimize command. Heads-up if you run behind an LLM gateway or with telemetry off: auto mode now asks or denies calls the server can't check, with no fallback to the built-in classifier unless you set CLAUDE_CODE_AUTO_MODE_SERVER=0. Bash deny rules also now catch quoted-word commands. Codex CLI 0.167.0: codex agents --no-daemon opens an agent command center with unread markers, the session picker switches backends without losing your draft, plus image previews and a Vertex AI sign-in wizard. Claude Code release · Codex release

Why it matters to you: if a client routes Claude Code through LiteLLM or another proxy, auto mode behavior just changed under them, so check /status before Monday. And denyInsteadOfPrompting is the setting you want for CI and scheduled agents.

9. libghostty-vt 1.0: a stable C ABI for terminal emulation

Mitchell Hashimoto shipped libghostty-vt 1.0 (~720 points on HN): Ghostty's terminal core as an MIT-licensed C library with an ABI stability policy enforced in CI (libabigail, versioned ELF symbols), distro-ready tarballs, and builds for Linux, macOS, iOS, Windows, Android, FreeBSD, and WASM (under 1 MB). It already powers the JetBrains IDE terminal (12.5M+ users per JetBrains), Turborepo's TUI, OrbStack, and agentic terminals like cmux. Neovim has an approved PR to replace libvterm with it. He ran 10,000 live terminals on a 4-core, 8 GB box. mitchellh.com · HN

Why it matters to you: if you're building an agent UI that shows or drives shells, don't write your own emulator. libghostty (or the xterm.js-compatible ghostty-web) gets you a correct, fast terminal in about 1,500 lines of C or through the bindings.
