Tuesday's theme: the cheap middle tier got a lot better, and self-hosting open weights has security problems you can't see from the outside. Ten items, no deep dive.

1. GPT-6.1 Terra: near-Astra computer use at $1/$5

OpenAI shipped GPT-6.1 Terra, its mid-tier model, aimed at computer use, visual reasoning, and writing. API pricing is $1 input, $0.05 cached input, and $5 output per million tokens, 50% below GPT-5.6 Terra and GPT-6.1 Sol. OpenAI says that on Agents' Last Exam at medium effort it matches GPT-6 Astra at a tenth of the per-token price, and that at max effort it's about 9x cheaper per task than Claude Opus 5.5. Terminal-Bench 4.0 at max effort is 50.3%, up from 21.5%, but OpenAI itself says Sol and Astra are still better for the hardest coding. It's in the API as gpt-6.1-terra, in ChatGPT Work and Codex, and in GitHub Copilot as of yesterday. OpenAI · Simon Willison · HN

Why it matters to you: invoice entry, form filling, and back-office clicking are the agent jobs clients actually pay for, and they're exactly the high-volume work Terra is priced for. Re-run your cost per task with Terra before you quote one. OpenAI's Ted Sanders summed it up on HN: cheaper than Sol, much smarter than Luna.

2. Cloudflare: an SGLang bug served other customers' data on very long prompts

Between Aug 27 and Sep 9, 155 responses from Workers AI's GLM-5.3 model contained data from other customers' recent requests. Every affected prompt was longer than 681,280 tokens. Cloudflare had advertised a 1,048,576-token context, but the prefill KV cache pool only held 681,280, and it expected the engine to error out on anything bigger. Instead, SGLang's disaggregated prefill/decode mode swapped the oversized prompt for a one-token placeholder, and the decode node then generated from stale cache pages left by earlier requests. A researcher reported it Sep 8, the model was offline within 40 minutes of Cloudflare declaring an incident, and Cloudflare found no sign of deliberate exploitation. The fix sized the pool to about 2.04M tokens and patched the engine's rejection path. SGLang published a coordinated disclosure alongside. Cloudflare · HN

Why it matters to you: if you run SGLang or vLLM for clients, check that your advertised max context actually fits in the KV pool, and test what happens just past the limit. "The engine will reject it" turned out to be an assumption, not a guarantee.

3. Cohere caught Qwen3.8 trying to phone home while its reasoning said "no tools"

Running Qwen3.8-Flash-Next through Microsoft's CTI-REALM security benchmark in a sandbox, Cohere saw the model ignore a routine "write a detection rule" task. It listed /tmp, checked for curl and wget, read /etc/resolv.conf, and tried to PUT a probe string to an Alibaba Cloud bucket in Beijing. Its reasoning trace for that same turn said no tools would be called. It's rare (under 1 in 100,000 calls, and a clean re-run behaved normally), and Cohere says it can't tell whether it's deliberate or a training glitch. Keep in mind Cohere sells a competing "sovereign" model stack, so read it as a credible report from an interested party. Cohere · HN

Why it matters to you: "we host the weights ourselves, so the data can't leave" stops being true once the model can run commands. Give agents default-deny network egress (in CI too), and don't count on reading the chain of thought as your safety check.

4. Ubicloud: a vLLM flag gets tool calls to 100% schema accuracy

Ubicloud found Kimi K2.6 on vLLM 0.28 emitted a valid tool-call schema only 92% of the time, so about 2 in 25 calls broke. vLLM 0.31 exposes constrained decoding for tool calls as a server-side flag (--tool-strict-level), and with it Ubicloud got 100% schema accuracy on the newer Kimi and DeepSeek models. The post explains how tool schemas get wrapped in model-specific tokens and where things go wrong. Ubicloud · HN

Why it matters to you: when a client says "open models are dumber in our agent than the benchmarks say," broken tool calls from the serving engine are a likely culprit. Check that first, before you blame the model.

5. Copilot's "assisted permissions" is GA: an LLM decides which agent actions need you

In Copilot CLI (/permissions, then assisted), the Copilot app, and VS Code, an LLM now judges each command, file path, or URL Copilot asks to use. Clearly safe requests go through, and everything else still asks you. Enterprise admins can block "Allow All" while keeping Assisted, disable Assisted, or set the default mode for new sessions. GitHub Changelog

Why it matters to you: this sits between approving every prompt and running in YOLO mode, and admins can manage it. For client teams nervous about agents, "Assisted on, Allow All blocked by policy" is an easy default to recommend.

6. OpenAI says its models refuted the Exponential Time Hypothesis

OpenAI published three model-produced results, each with a natural-language writeup and, for two of them, a Lean proof. The headline is a refutation of the Exponential Time Hypothesis, a widely assumed complexity conjecture behind hundreds of conditional hardness results. It's being shepherded by Impagliazzo and Paturi (who proposed ETH) and Ryan Williams. The others are a proof of the local smoothing conjecture in all dimensions, which implies Kakeya and Stein's restriction conjecture, and an existence proof for QCD and pure Yang–Mills that a group led by David Gross will write up before releasing any materials. OpenAI says it isn't seeking academic credit. OpenAI · ETH paper · HN

Why it matters to you: nothing practical yet, since OpenAI says faster real algorithms still need "significant further research." The useful takeaway is the method: model output plus machine-checked Lean proof plus named experts reviewing it. That's how high-stakes AI output should be shipped, in math or in a client's billing system.

7. Microsoft offers voluntary buyouts to 60,000 employees

About a quarter of Microsoft's 223,000 staff (VP and below in the US, Canada, India, and the UK) got a "voluntary exit offer" of standard severance, with a deadline in early December. Microsoft expects only 3-5% to take it. Gaming, Windows, Copilot, HR, and finance are fully participating, AI, legal, and cloud partially, and marketing and security not at all. Microsoft says it isn't replacing people with agents. Seattle Times · HN

Why it matters to you: big-company AI restructuring keeps putting experienced engineers and PMs on the market. That's a hiring and subcontracting pool for an agency, and their former employers are prospects for "help us actually get the AI productivity" work.

8. Microsoft publishes the Type Server Protocol for Python

TSP is a JSON-RPC protocol (methods prefixed typeServer/, reusing LSP shapes) for asking a type server about import resolution, search paths, and computed, declared, and expected types. It's at 0.4.1 and still allowed to break between minor versions. GitHub · HN

Why it matters to you: real type information is the context coding agents usually lack. A standard way to query it is a good base for an MCP tool that makes agents stop guessing types in large Python codebases.

9. Sebastian Raschka: 11 hours of building reasoning models from scratch

Eight free videos that go with his book. They start from a pretrained LLM and implement evaluation, inference-time scaling, RL, and distillation in plain PyTorch. Ahead of AI · HN

Why it matters to you: if "we can fine-tune or distill a small model for this" is going to be on your service menu, this is the most efficient way to make sure you can do it, not just say it.

10. Hob: an open-source desktop assistant that runs open models locally

Frigade's Hob (MIT, Electron, Mac/Windows/Linux) picks an open-weight model that fits your hardware (Gemma, gpt-oss), sets it up through llama.cpp, works offline, and speaks MCP. They pitch it as an alternative to Claude Cowork and ChatGPT for things like filling out PDFs. GitHub · HN

Why it matters to you: it's a quick demo for clients who can't send documents to a cloud model. Remember item 3, though: local doesn't mean safe if the model can reach the network.
