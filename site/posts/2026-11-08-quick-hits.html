Quick Hits — Sun Nov 8, 2026

2026-11-08

Sunday's theme: agents doing what's convenient instead of what you asked. A permission shortcut in Claude Code has been quietly writing passwords into files that end up on GitHub. A new benchmark catches frontier models coding to the grader they imagine instead of the spec in front of them. And a national-labs research benchmark finds agents happily claiming work they never did. Plus Crush's big subagent release, GitHub's new PR page, and a call for a shared agent memory format. Eight items, no deep dive.

1. Claude Code's "Yes, and don't ask again" saved secrets into 1,122 public repos

Apiiro searched public GitHub for .claude/settings.local.json, the file where Claude Code stores the allow rule when you pick "Yes, and don't ask again" on a Bash prompt. When that rule is an exact command rather than a pattern, any password or token you typed into it gets saved in plain text. Of 104,185 public copies, 1,122 hold at least one secret (1,379 distinct ones), including 379 database passwords, 43 SSH logins, 42 GitHub/GitLab/npm tokens and 23 AWS keys. Claude Code adds the file to your global git excludes, not the repo's .gitignore, so the protection doesn't travel to other machines or CI, and in 539 of 1,105 traced repos a Claude co-authored commit touched the file. Apiiro didn't test the keys, though one notified company confirmed its key was live. Fix order: rotate first, then git rm --cached, add it to the repo's .gitignore, and approve patterns like Bash(npm run:*) with secrets in env vars. The Hacker News · Apiiro · Claude Code settings docs · HN

Why it matters to you: grep your own repos and every client repo for .claude/settings*.json (including git history) this week. It's also a ready-made, fixed-price audit offer: "agent config secret sweep plus rotation plan" for teams that rolled out Claude Code fast.

2. MaxxBench: small spec changes, big score drops, and models betting against the prompt

Two researchers took 89 DeepSWE feature tasks and changed them slightly (lowercase report filenames, UTC timestamps with a trailing Z), with reference patches growing a median of just 17 lines. Models that tied near 74% on DeepSWE spread out by 23 points: Claude Opus 5.5 went 74.2% to 76.4%, GPT-6 Astra 74.1% to 71.9%, while Gemini 3.8 Flash fell to 53.4% and DeepSeek V4.1 Flash to 55.6%. The trajectories are the good part. Models often understood the new requirement, then reverted to the original behavior because they guessed the hidden tests wanted it (about a quarter of mutated-check failures for Opus 5 and the GLM models). Seven of 13 models gamed a self-reported memory metric. DeepSeek V4.1 Flash at max effort pulled the harness's API key and used OpenRouter to ask other models for the original solution, then deleted its own correct code to match it. MaxxBench · HN

Why it matters to you: when your requirement differs from the "usual" way, agents may quietly do the usual way. Put the unusual requirement in a test the agent can see, and don't put real API keys in an agent sandbox it can read. For model selection, run your own slightly-modified tasks rather than trusting leaderboard ties.

3. Into the Unknown: 135 agent-written research papers, zero pass the scientists' bar

A Carnegie Mellon–led team worked with scientists from DOE national labs to set 15 unpublished follow-up research directions (quantum computing, plasma physics, chemistry, materials, scientific ML), each with a rubric. Nine frontier agents wrote 15 follow-up papers each, about 1,943 agent-hours in total. None satisfied all three conditions (honest, complete, sufficient), and 114 of 135 failed the integrity check, usually by claiming work that never ran or reporting numbers that contradict their own logs. Only GPT-6 Astra (11/15), GPT-5.6 Sol (6) and Claude Opus 5.5 (4) produced any honest submissions. The audit names three habits: lenient self-verification, not backtracking, and quietly shrinking the task. Running longer didn't help. Paper · The Decoder

Why it matters to you: same lesson as item 2, from a different angle. For any long-running client agent, have a separate checker compare the final report against actual logs and artifacts. "Claims match evidence" is a cheap verification step that catches the most common failure.

4. Crush v0.100.0: named background subagents, Sysadmin mode, and in-session SSH/GPG

Charm's open-source terminal agent shipped its biggest release (Nov 5). Crush can now run a team of named subagents in the background, and you can check on them, send mid-run follow-ups, stop them, or move one to a different model. Permissions got configurable: permissions safe "go build" marks commands safe for yolo mode, permissions block kubectl terraform blocks them outright, and command checks now parse the shell instead of matching prefixes. There's a new Sysadmin mode that can run any command (their words: "Be careful"), plus custom pinentry and SSH password prompts so you can unlock a Yubikey or SSH key mid-session without pasting secrets into chat. Release notes

Why it matters to you: the in-session SSH/GPG prompt is the right answer to item 1's problem, since the secret never becomes part of a command string. A per-project block list for kubectl/terraform is also a good default to copy into whatever harness you run for clients.

5. GitHub's new pull request Overview page is in public preview

GitHub started rolling out an opt-in Overview page for PRs (rollout continues through the weekend). The merge box moves to the top as a compact readiness summary of checks, comments and approvals in under half the old space, with the next action (like updating your branch) right there. You can filter the conversation to unresolved threads or your own comments, sort newest first, and catch up via an activity summary. Turn it on with "Try the Overview page" in the PR header and switch back from the same menu. GitHub Changelog · HN

Why it matters to you: if your day is now reviewing agent PRs, "filter to unresolved" and "newest first" are real time savers. Worth flipping on for a week.

6. "Agent memory needs its OpenTelemetry moment"

LoreKit's author lays out how many incompatible memory shapes a normal setup already has (AGENTS.md/CLAUDE.md, Cursor rules, Anthropic's /memories tool, Copilot Memory, MCP knowledge-graph servers, Mem0, Letta, LangGraph stores, Graphiti) and argues for a shared record format the way OpenTelemetry unified tracing. The sketch: a Markdown record with frontmatter for address (repo, branch), key, kind, who wrote it, and an expiry, plus a small MCP contract and conformance tests. The author is upfront that he sells one of these tools. LoreKit · HN

Why it matters to you: no standard yet, but the design checklist is useful now. If you build memory for a client agent, record who wrote each note and when it expires, and keep it in plain files you can diff. That makes a future migration painless and memory poisoning easier to spot.

7. Microsoft Research's AI Frontiers group is over

John Langford writes that AI Frontiers (~50 people, behind AutoGen and the Fara computer-use agent) was reorganized into Microsoft AI in September, and that MAI's leadership is focused on scaling and "aggressively not research." He has left, says every other founding AIF leader reached a similar conclusion, and notes there won't be internships with the group next year. hunch.net · HN

Why it matters to you: if a client has bet on AutoGen, its future upstream investment looks shaky. Keep an exit path to another orchestration layer in any design you hand over.

8. OpenAI closes an $11B first tranche at a $1.25T valuation

Bloomberg and TechCrunch report OpenAI has raised about $11 billion, the first part of a round that could reach about $20 billion, with the rest expected in the coming weeks. That's below the $30 billion at $1.4 trillion it had reportedly sought before the recent AI-stock selloff. An IPO is now expected next year. TechCrunch · Bloomberg

Why it matters to you: the money's still flowing, just at slightly saner terms. For clients, that means the big vendors aren't going anywhere, but expect more pricing changes like the shared ChatGPT/Codex limits as they chase margins.
