Today's theme: when agents write the code, everything downstream of the keyboard breaks first (source control, review, CI, even your compiler's guarantees). Plus a new frontier model worth benchmarking this week. Eleven things for your Wednesday.

1. Gemini 4 Argon is out, priced to get tried

Google released Gemini 4 Argon to developers and enterprises via the Gemini API and AI Studio, to Ultra subscribers in Antigravity, and to Pro/Ultra users in the Gemini app. Pricing is introductory: $2 per million input tokens and $10 per million output (cached input 95% off) until November 30, then $4/$20. The API has a 1M-token "unified input-output" limit and a new continuation protocol you'll want to read up on before wiring it into a harness. Google's own claims: #1 on the Vals Index, more than 35% more agentic code submissions in Antigravity with nearly a third fewer rollbacks, and a 2% shortcut-attempt rate on coding benchmarks. GitHub made it generally available in Copilot the same day for Pro+, Max, Business and Enterprise (VS Code, Visual Studio, JetBrains, Xcode, Eclipse, Copilot CLI and the coding agent), billed at provider list price, and on by default for orgs unless admins have turned off new-model enablement. Google · Google for Developers · GitHub Changelog · HN thread

Why it matters to you: frontier-class output at $10/M for the next seven weeks is cheap enough to point at your long-horizon jobs (migrations, big refactors) and compare it against what you run now. Budget for the price doubling on Dec 1. If you manage Copilot for a client, check the model policy today, because "auto-enabled at list price" is a billing surprise waiting to happen.

2. Anthropic replaced git after merges went from 2,500 to 30,000 a day

Anthropic's engineering post explains Scion, an in-house, always-online version control system built by a seven-person team and migrated to in five months, along with a code review tool called Antique. The numbers driving it: main-branch history near 100 GB, a working copy over 25 GB, and around 25 million CI checkouts a day ("over 600 PB of git traffic per day" if fetched naively). The design leans on server-side history, blame and merges, sparse or virtualized checkouts, and a tiered cache. They gave up a global merge-queue lock and rely on post-merge and pre-deploy testing instead. Anthropic says Scion is "by no means a suitable replacement for git for general use" and isn't releasing it. Anthropic · Simon Willison · HN thread

Why it matters to you: you don't need Scion, but you should expect the bottleneck it describes. If a client's agent adoption works, merge volume, CI checkout cost and review queues blow up next. Shallow and sparse clones, cached CI checkouts, trunk-based flow and strong post-merge tests are a concrete "agent-readiness" engagement you can sell before things fall over.

3. Rust's borrow checker had a soundness hole going back to 2015

A rust-lang issue filed yesterday shows safe Rust code that compiles and then reads freed stack memory: a struct's lifetime bounds can be bypassed by assigning a shorter-lived reference into a field, with a Drop impl then treating it as 'static. Contributors produced variants that compile back to Rust 1.4.0 (2015), and Miri flags the undefined behavior. It's labeled I-unsound and P-high. The types team's note says that triggering it on purpose takes a deliberately malicious Drop implementation, and it's unlikely to have caused memory unsafety by accident. rust-lang/rust #164250 · HN thread

Why it matters to you: no need to panic, but "it compiles, so it's safe" is a guarantee about the compiler, and compilers have bugs. If you lean on Rust's type system as the guardrail for agent-written code (see item 4), still run Miri and sanitizers in CI on anything with custom Drop or unsafe, and look twice at weird lifetime gymnastics in agent PRs.

4. Niko Matsakis on what agents mean for Rust

Companion post to Niko's REBASE/SPLASH talk. He argues Rust fits agentic coding well because the type system keeps agents on track where tests alone don't, and because agents are good at tuning performance with a profiler in the loop (benchmark → profile → agent → PR). He quotes David Tolnay that Meta engineers have written twice as much first-party Rust this year as in the previous nine combined. His proposals: make "if it compiles, it works" more expressive, integrate proof tools like Verus and Kani through an extensible compiler, and set a north star of provably sound unsafe code. He also calls design and specification the open problem. baby steps · HN thread

Why it matters to you: the practical pattern carries over to any language. Give agents strict, machine-checkable success criteria (types, newtypes, property tests, benchmarks) and let them grind. The tighter the spec, the more of the work you can safely hand off.

5. OpenAI engineer charged with bugging an executive conference room

The DOJ says Abdulrahman Alfozan, an OpenAI engineer since July 2025, was arrested Oct. 9 and charged with intercepting oral communications. OpenAI found an encrypted audio recorder, wrapped in toilet paper and plugged into a TV's USB port, in an executive conference room on Sept. 30. Per the complaint, CCTV showed him near the room on several dates, and a bag he left elsewhere in the office held his wallet, ID and a second recording device. OpenAI says it fired him and coordinated with the FBI. DOJ · The Verge · HN thread

Why it matters to you: AI labs are now espionage targets, and so is anyone holding their secrets: model weights, eval data, a client's proprietary prompts and pipelines. When you build for clients, scope access to need-to-know and keep audit trails, because your consulting shop is part of their attack surface.

6. Ledger wallet implants turn up through authorized resellers

Ledger said a hardware backdoor in a limited number of Nano X wallets sold by CryptoBilis, an authorized Malaysian reseller, was behind last week's thefts, which blockchain firm Bitquery puts at about $102 million. Kim Zetter reports the implants (an extra flex circuit, an LTE module and an eSIM that capture the seed phrase as it goes to the screen and transmit it) have since appeared in devices bought at MediaMarkt in Germany and in Flex and Stax models. Joe Grand first reported implants to Ledger in March. Trezor is cutting its own approved-seller list as a precaution. Zero Day · HN thread

Why it matters to you: "buy from an authorized channel" stopped being enough. The same thinking applies to agent supply chains: MCP servers, model weights and npm packages that arrive through a trusted-looking channel. Verify artifacts (signatures, checksums, provenance) rather than vendors.

7. Character.ai files for Chapter 11 to sell itself

Character.ai started a voluntary Chapter 11 process for a court-supervised sale, citing "significant legal, regulatory, and operational headwinds." It expects the sale to finish by late November or early December. If no workable bid comes in, the platform will be wound down. Service and subscriptions continue for now, and users can export their data. Character.ai · HN thread

Why it matters to you: consumer AI apps carry legal and regulatory risk that can sink a well-known product. For clients, build on vendors you can swap out, keep data exportable, and treat any AI dependency without a contractual exit plan as a risk.

8. Firefox Enterprise: on-prem browser governance with AI controls

Mozilla launched Firefox Enterprise, a console you can deploy on your own infrastructure. It includes centralized policy, native DLP that warns or blocks sensitive data actions by domain, controls to allow, restrict or disable AI tools, SIEM export, extension governance, a Lockdown Mode, and professional support. Thunderbird management runs from the same console. Firefox · HN thread

Why it matters to you: "which AI tools can staff paste data into?" is a question every client's CISO is asking. Browser-level AI and DLP policy is a cheap, enforceable answer, and a natural first deliverable in an AI-governance engagement for regulated clients.

9. Apple paper: a GPU cloud built from idle Macs

Apple ML Research published "Minions," a system that pools idle Apple Silicon GPUs across macOS machines into a distributed virtual GPU cloud for large ML inference jobs, with flexible task execution and fault tolerance. The authors say it works as a practical inference platform where central GPU capacity is limited. Apple Machine Learning Research · HN thread

Why it matters to you: plenty of clients have a fleet of M-series laptops that sit idle every night. Batch jobs that can wait (embedding backfills, document classification, eval runs) on hardware they already own is a pitch finance teams like, though the scheduling and data-handling details are on you.

10. One "AI newsletter" bot was half a small site's traffic

After a Show HN, the developer of sprinklz.io saw his site slow down for days. Endpoint logging showed most requests never ran the SPA's JavaScript. Nginx logs put nearly half the traffic on a single service that polls sites for changes to summarize into AI newsletters, hitting it many times a minute. The rest came from declared AI crawlers and vulnerability scanners. His fixes: block the abuser, a robots.txt that allows search bots and discourages AI scrapers, rate limits, and performance work. Sammy Straus · HN thread

Why it matters to you: any client site that gets attention will get scraped hard. Put per-path request logging, per-client rate limits and a bot policy in your launch checklist. And if you build monitoring or scraping agents yourself, cache aggressively and back off, so you're not the bot in someone else's post.

Fish Audio released Drama 3, a text-to-speech model you direct in plain language ("play this line angry, then break"), in 83 languages. It's aimed at rendered content like audiobooks, game dialogue and short video. It's on fish.audio, the mobile apps and the API (model header drama-3). The API is $10 per million characters through November 12, down from a $50 list price. Fish Audio
