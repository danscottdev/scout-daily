Today's theme: open weights, open sandboxes, and security that actually remediates. Ten things for your Friday, plus a deep dive on Anthropic ditching git for agent-scale source control.

1. Meta ships Muse Spark Open: 816B MoE, 42B active, 1M context, built for agents

Meta released the weights for Muse Spark Open, calling it the most capable US open-weight model to date. It's a natively multimodal sparse MoE with 816B total parameters, 42B active per token, and a 1M-token context window, trained for long-horizon coding and tool use. Day-0 runtimes include vLLM, SGLang, TensorRT-LLM, MLX, llama.cpp, and Unsloth. Hosted APIs are up on Baseten, Fireworks, Groq, Modal, Nebius, OpenRouter, and Together. Meta's headline local demo: two Apple M5 Ultra Mac Studios via MLX (up to 512 GB unified memory each). Weights are also on Hugging Face, SageMaker, Cloud Model Garden, and Foundry. License is the Muse Model License with limited commercial terms — open weights, not "do whatever." Extra safety post-training for standalone use without lab guardrails. Meta AI Research · PyTorch · vLLM day 0 · HN thread

Why it matters to you: a serious US open-weight coding model with a 1M window is useful for clients who want private agent stacks. Benchmark it on your own harness before you pitch it, and read the commercial terms carefully — "open weights" still has a license.

2. GitHub AI Scan for pull requests is generally available

Code scanning's AI Scan for PRs is GA. It catches vulnerabilities in languages and formats CodeQL doesn't cover yet: PHP, Shell/Bash, Terraform (HCL), Dockerfiles, JSP, Blazor, and more. Findings show up next to CodeQL on the Conversation and Files changed tabs with an "AI" badge, often with a risk explanation and suggested autofix. Findings are advisory — they don't fail the check or block merges via rulesets. No runs on fork PRs or Dependabot PRs. Public repos get it; private/internal org repos need GitHub Code Security or Advanced Security. No Copilot license required. Billing is Code Security AI Credits. GitHub Changelog

Why it matters to you: turn it on for repos heavy on shell, Docker, and Terraform — the gaps CodeQL leaves in infra-as-code and ops scripts. Set an AI Credits budget before a large org enablement, and treat findings as triage signal, not merge gates.

3. Agentic autofix for code scanning alerts is GA

Assign a CodeQL alert to Copilot and it explores relevant files, proposes a fix, reruns CodeQL to confirm the alert is closed, iterates if needed, then opens a draft PR with a summary of why the fix works. You can assign up to 25 alerts into one PR from the alerts list or a security campaign, or hit the REST API with assignees: ["copilot-swe-agent[bot]"]. Default-branch alerts only. Enterprise admins must enable the "Agentic autofix" Advanced Security policy; then org/repo admins turn it on. Needs a Copilot billing method. Consumes Code Security AI Credits plus Actions minutes. GitHub Changelog

Why it matters to you: this is the sellable "alert to validated PR" loop clients keep asking for. Start with a security campaign of high-confidence alerts, require human review on the draft PRs, and meter AI Credits so it doesn't surprise finance.

4. Anthropic gives METR employee-like access for independent evals

Anthropic onboarded six METR employees with company hardware, office space, and internal tools roughly on par with its own risk-assessment teams. METR can publish on risk levels, incidents, and practices; Anthropic cannot veto publication but can require redaction of narrow categories (customer data, privilege, model architecture). METR may publicly characterize those redactions. Anthropic says it isn't funding METR's work. SecureBio and Accenture are earlier-tier evaluators; Hugging Face is in early talks. Three access tiers are defined, with METR at tier three. Anthropic · CNBC

Why it matters to you: when clients ask "who audits the labs?", this is the concrete answer for Anthropic. For your own agent products, the usable pattern is independent reviewers with publish rights and a short, predefined redaction list — not NDAs that bury findings.

5. Perplexity open-sources SPACE, the Firecracker sandbox behind Computer

Perplexity released SPACE (Sandboxed Platform for Agentic Code Execution) under Apache 2.0. It's a Rust platform that runs agent and user code in isolated Firecracker microVMs, each with its own guest OS and writable filesystem. An HTTP/SSE API covers create, run commands, stream output, lifecycle, pause/resume, and snapshots. Credentials and network policy stay outside the guest. Docs cover local Kind deployment on KVM Linux hosts. Perplexity · GitHub · docs

Why it matters to you: another production-shaped agent sandbox you can study or fork instead of inventing isolation from scratch. Pair it with default-deny egress and short-lived tokens when you build client computer-use systems.

6. OpenUI 1.0: generative UI as a first-class agent response

Thesys's OpenUI Lang hit 1.0. Agents emit interactive UI (cards, charts, forms, actions) instead of walls of markdown. 1.0 adds custom @ functions, custom actions with typed onAction handlers, library.extend to derive component libraries, a message format for store/replay, and shorter single-action syntax. React runtime is at 1.0; Vue, Svelte, and Angular stay on 0.4 for now. OpenUI docs · Build agents

Why it matters to you: chat-only agent UIs are a ceiling for client tools. A schema-driven generative UI layer is a product differentiator for internal ops agents (approvals, dashboards, triage) you can sell as more than a chatbot wrapper.

7. Copilot in Slack and Teams now spans multiple repos in one chat

GitHub Copilot in Slack and Microsoft Teams can work across multiple repositories in a single conversation — open PRs across repos, weekly merges, cross-repo investigations, activity summaries. Mentions of @GitHub work anywhere in the message, repo switching is smoother, Slack thread/shared-message context is usable, and recovery from interruptions improved. GitHub Changelog

Why it matters to you: most client work spans frontend/backend/infra repos. This cuts the "which channel was that in?" tax for eng managers. Worth enabling where Copilot chat is already allowed in Slack.

8. Copilot retires Opus 4.8/5 and GPT-5.6 Terra on Nov 16

On November 16, 2026, GitHub removes Claude Opus 4.8, Claude Opus 5, and GPT-5.6 Terra from all Copilot surfaces (chat, edits, ask/agent, completions). Suggested replacements: Claude Opus 5.5, and GPT-6.1 Sol or GPT-6 Luna. Exception: Opus 4.8 stays for individual Copilot subscribers on annual plans. Business/Enterprise get alternatives via default model enablement unless admins disabled the global default. GitHub Changelog

Why it matters to you: audit any hard-coded model IDs in Copilot workflows, org policies, and client runbooks before mid-November. Pinning an old Opus id will break quietly for teams that aren't watching changelogs.

9. Goodfire: maybe neural nets were already "clean"

Nick Cammarata's long Goodfire essay argues that classic polysemanticity examples were often misread: many "tangled" neurons look like recursive generalization (coarser shared motifs) rather than arbitrary concept packing. With agentic interpretability tools, he claims most neurons up through huge models look legible — preliminary Qwen3-32B audits around ~90% of neuron poles with one main job. Explicitly a working hypothesis with a technical paper still coming; Neel Nanda and others on HN called it useful for practical debugging but not proof that ambitious reverse-engineering is solved. Goodfire · HN thread

Why it matters to you: treat it as a research signal, not a compliance checkbox. If it holds up, cheaper neuron-level debugging of "why did the agent do that?" becomes more realistic for production incidents — still verify on your own models.

Google said more than 400 publications worldwide now participate in its News AI pilot, licensing enhanced content for AI features (overviews, audio briefings) with attribution and links back. Newly named partners include Axios, CNN, the Financial Times, Forbes, and several US local outlets. Google · Nieman Lab
