Today's theme: review is the bottleneck now, and open weights keep getting more serious. Nine things for your Saturday, plus a deep dive on the Claude Code team's review stack, which is the most copyable process doc I've read this month.

1. Claude Code Review is GA, and Anthropic published the playbook behind it

Code Review for Claude Code is out of research preview for Team and Enterprise orgs. It runs multiple agents on each GitHub PR, has other agents vote on findings before anything posts, and leaves inline comments ranked by severity. Admins pick Quick, Standard, or Deep per repo. Typical turnaround dropped from about 20 minutes in preview to 6-10 minutes. It posts findings, never approvals. Caveats: not available with Zero Data Retention, the HIPAA configuration, or customer-managed encryption keys. Eligible Enterprise orgs can claim at least $10,000 in Code Review credits by Jan 15, 2027. Anyone on any plan can run the lighter local /code-review. Alongside it, the Claude Code team wrote up its own process: merged PRs more than doubled from June to September while the revert share fell more than 40%. Claude · claude.dev engineering post · docs · HN thread

Why it matters to you: "AI review that actually holds up" is a service line. The product is the easy part; the process around it is what clients need help with. See today's deep dive.

2. Reflection releases Beam: 501B MoE, 23B active, 1M context, Apache 2.0

Reflection's first open-weight model is out. Beam is a sparse MoE with 501B total and about 23B active parameters, a 1M-token context, text in and text out, built for coding and long-horizon agent work. Checkpoints ship in BF16 (about 934 GiB), FP8 (about 469 GiB), and NVFP4 (273 GiB), plus a DFlash2 drafter for speculative decoding. The reference self-serve setup is four NVIDIA B300s. It comes with its own open-source Rust harness, day-0 support in transformers, vLLM, and SGLang, SFT and RL recipes from Hugging Face, and hosted access on AWS, Google Cloud, Foundry, Fireworks, Together, OpenRouter, Ollama, OpenCode and more. The license is the real story: plain Apache 2.0. Reflection · Hugging Face blog · model card · serving docs

Why it matters to you: compared with Thursday's Muse Spark Open, Beam's Apache license is far easier to put in a client contract. For "private coding agent on our own cloud" pitches, it's now the default model to benchmark first.

3. DeepSeek V4.1 Flash 1017: a "minor update" with big agentic jumps, MIT license

DeepSeek pushed V4.1-Flash-1017 to Hugging Face under MIT. The weights index lists about 763B parameters (FP8/INT8 mix), and it takes image plus text input. DeepSeek's own table shows Terminal-Bench 4.0 jumping from 31.2 to 42.3 and DeepSWE v1.1 from 74.2 to 77.0 over the previous Flash. It also claims shorter outputs and faster task completion. It's already on OpenRouter. Those are vendor numbers, run on the Claude Code harness for Terminal-Bench, so verify them on your own tasks. Hugging Face · OpenRouter · HN thread

Why it matters to you: it's a cheap candidate for the bulk tier of an agent router (subagents, triage, codemods) behind a frontier model. Before you put it in client work, check data residency and the client's procurement rules on Chinese-origin models.

4. GitHub open source license compliance is GA, with an API agents can call

GitHub Enterprise Cloud customers with Code Security, including data-resident GHEC, can now set one enterprise-wide license policy and enforce it with a ruleset condition, "Require license compliance results before merging." PRs that add or change dependencies get annotated for any noncompliant license, and exceptions route to a new Enterprise Open-Source License Manager role. New since the June preview: policy changes write audit-log events, there are APIs to manage the policy, and there's an endpoint to check whether packages comply. GitHub says that one exists so coding agents stop suggesting packages that break policy. GitHub Changelog

Why it matters to you: agents add dependencies freely. Wire that compliance endpoint into your agent's tool belt or a pre-PR hook, and license problems get caught at suggestion time instead of during legal review.

5. Claude cracked the 26-year-old mystery of the NIST curve seeds in under 30 minutes

The NSA-supplied seeds behind NIST P-192 through P-521 were never explained, which fed years of backdoor speculation. An Anthropic employee asked an internal research model to work it out, without giving it the old "hash of a joke passphrase" rumor. In under half an hour it found the answer: no hash at all, just output from the C library's lrand48 generator seeded with a Unix timestamp. P-256's seed was candidate number 1842. Claude got there by writing a scanner that tested whether chunks of each seed were consecutive outputs of 1990s-era generators. Anthropic says this isn't a break, and if anything it makes a backdoor less plausible. Anthropic · HN thread

Why it matters to you: the useful pattern is the method. The model reasoned about how the generating software must have worked, then wrote a tool to test that guess. Brief agents that way on forensics and legacy-system archaeology work.

6. Mercor: 90% of US working hours sit on tasks benchmarks barely cover

Mercor mapped 29 AI benchmarks onto all 923 O*NET occupations. Only 208 occupations have a task with at least 5 benchmark prompts, and 6 of 22 job families have none. Their estimate is that 90% of American working hours go to tasks with little or no benchmark coverage. Computer and math jobs are well covered (29 of 36 occupations); healthcare practitioners (12 of 89) and education (9 of 62) are not. Mercor · HN thread

Why it matters to you: for most client domains, public leaderboards tell you almost nothing. A custom eval set built from the client's real tasks is a deliverable worth charging for, and a strong opener for any engagement.

7. China drafts export controls on frontier model weights and advanced agents

China's commerce and science ministries proposed adding 40 technologies to the export-control catalog, 23 of them AI. Model weights, checkpoints, source code, and training methods would be restricted if a model passes any one of these: 10^26 FLOPs of training compute, 2 trillion parameters, or a global top-10 public ranking. Advanced agents are covered too (for example, planning into 20 or more sub-tasks, or using 200 or more tools). Serving a model by API, app, or SaaS is excluded, and so is anything already open-sourced. Comments close Nov 15, and pre-export registration applies now. MOFCOM (Chinese) · On The Wire

Why it matters to you: weights that are already public stay usable, but a future frontier Chinese release might ship API-only. Don't build a client architecture that assumes the next big open Chinese model will come with weights.

8. FLUX 3 Image Klein: 5.6B open weights that run on an 8 GB GPU

Black Forest Labs released FLUX 3 Image Klein, a 5.6B model for text-to-image, editing, and multi-reference generation (up to 10 references). It supports native 4K and bounding-box control over where edits land. Weights take 11.2 GB in BF16 and 5.6 GB in FP8, and the INT8 build runs on RTX cards with as little as 8 GB of VRAM through ComfyUI or Diffusers. It ships as a base model plus a step-distilled model. The license is the FLUX Kommunity License, not Apache, so check commercial terms. Black Forest Labs · HN thread

Why it matters to you: on-prem image editing for e-commerce, real estate, or marketing clients just got much cheaper to host. Bounding-box edits make "change only this region" workflows practical.

9. llmspeed: see how fast a local model will feel before you buy the box

A Show HN simulator streams tokens at the estimated speed for a given model and hardware combination, from a 3060 up to M5 Ultra Mac Studios, DGX Spark, and cloud H100/H200s. Numbers come from community benchmarks where they exist and are otherwise derived or projected from specs, and the site labels which is which. The code and data are open. llmspeed · GitHub · HN thread

Why it matters to you: a quick way to show a client what "local" actually feels like before they sign a hardware PO.
