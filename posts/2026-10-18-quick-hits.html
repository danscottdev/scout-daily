Today's theme: review gates and agent ops get practical, and model defaults and budgets shift. Ten Sunday items, plus a deep dive on Imprint's small-change gate — the natural follow-on to yesterday's Anthropic review stack.

1. Imprint's small-change: CI decides who skips the human queue

Will Larson published how Imprint is coping with merge volume that is crushing review. Average engineer merges are up 4x vs two years ago; some teams are at 10x; one engineer is at 25x. Incidents are down 42% half-over-half and critical incidents down 78%. The cost: p50 review time rose from about 33 minutes to 77. Their answer is small-change: a non-human-editable CI check that marks eligible PRs, plus a skill that may only approve or ignore — never comment. Eligibility: under 1,000 LOC; no p1/p2 from ai-code-review; author has 10+ prior merges in each affected service; impacts fewer than N services (N=1 frontend, N=3 backend); shared libs ineligible; path exclusions via .small_change (money movement, etc.). Early: about 10% of changes qualify. Failures from small-changes are treated as system failures, not human ones. lethain.com

Why it matters to you: this is the missing half of yesterday's Anthropic playbook — risk-tiered auto-merge with hard eligibility, not "AI left comments and a human rubber-stamped." Steal it for clients. See today's deep dive.

2. Replit makes OpenAI the default over Anthropic

At TechCrunch Disrupt, Replit CEO Amjad Masad said OpenAI is now preferred for Replit Agent on performance, cost, and partnership. Users can still pick Claude. Replit had been a top-5 Anthropic customer. Enterprise is about 15% of revenue (was 2%), and more than half of revenue is B2B. TechCrunch

Why it matters to you: agent platforms will keep flipping defaults on cost and partnership, not just quality. Multi-model routing and a "switch provider without rewriting the product" story are now table stakes in any consulting pitch.

3. Claude Code 2.1.301: safer unattended retries + richer OTEL

Unattended retry mode can now bail when a usage-limit reset is too far away: set CLAUDE_CODE_RETRY_WATCHDOG_MAX_USAGE_LIMIT_WAIT_MS instead of waiting forever. OpenTelemetry tool_decision events gain classifier_verdict, permission_mode, and (with OTEL_LOG_TOOL_DETAILS=1) classifier_category. Fixes worth noting: Grep/Glob no longer report empty results when the search failed; unsafe worktree deletion on quit; workflow agents that skipped steps but still reported success. Changelog (2.1.301) · errors docs

Why it matters to you: overnight agent fleets that hang on usage limits burn money and trust. Wire the watchdog and OTEL attributes into your client's observability before you sell unattended runs.

4. Next.js: two critical RCEs — patch to 15.5.28 or 16.4.1

Sunday catch-up on the Oct 14 security update. Critical: unauthenticated RCE when use cache returns typed arrays (GHSA-673q-mjm6-r5xr). Critical: Image Optimization SVG RCE on glibc Linux (CVE-2026-96889 / GHSA-2464-fhr4-w9xw); sharp ≥0.35.5 is a workaround. High: Server Actions DoS. Upgrade to 15.5.28 or 16.4.1. Next.js blog

Why it matters to you: any client on App Router with caching or image optimization needs this in the Monday morning checklist. Unauthenticated RCE is the kind of thing that turns a quiet weekend into an incident retainer.

5. REA: MCP reverse-engineering toolkit for coding agents

morluto/rea is an MIT-licensed MCP toolkit that lets coding agents do local analysis of binaries, JS, Electron, .NET, and websites via tools like Ghidra, Hopper, and IDA, with evidence-backed findings. Setup is npx rea-agents setup. The framing is owned software, interoperability, and study — not theft. Indie studios are already nervous about AI cloning demos. It has surged in popularity on GitHub. GitHub · docs · rea.tools

Why it matters to you: interoperability and legacy-binary archaeology are real consulting work. So is advising clients on policy: what agents may reverse-engineer on owned code vs what creates legal exposure.

6. Accenture caps central Claude funding at $29/employee/month

Effective around Oct 1 (reported Oct 15), Accenture limited centrally funded Claude spend to $29 per employee per month. Some employees had been spending up to about $1,000/month. Excess now hits project WBS budgets. A firm that sells AI to clients is tightening its own internal bill. 404 Media

Why it matters to you: expect the same conversation at every mid-size client. Sell usage budgets, per-project WBS routing, and "what $29/mo of Claude actually buys" as part of the rollout, not as a surprise finance memo later.

9. Sphinx: quiz yourself on AI-generated code before you push

Sphinx is a git-hook / CI idea that generates a quiz from your actual diff before you push to protected branches — so you ship code you claim to understand. Show HN landed around 146 points. sphinx app · HN · sphinx-ci

Why it matters to you: pairs cleanly with Imprint's small-change and Anthropic's risk tiers. For juniors and contractors, "prove you read the AI diff" is a cheaper control than mandatory human review on every PR.

10. Claude Code 2.1.302: fork subagents on by default in more surfaces

Quick follow-on to 2.1.301: fork subagents (subagent_type: "fork") are now on by default in claude -p, the Agent SDK, desktop, and VS Code (matching the terminal). Set CLAUDE_CODE_FORK_SUBAGENT=0 to turn them off. Idle compaction also gets an on/off row in /config. Changelog (2.1.302)

Why it matters to you: if a client's SDK or desktop agents suddenly behave differently after an upgrade, check fork defaults and compaction before debugging the prompt.
