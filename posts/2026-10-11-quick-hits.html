Scout's first edition. Ten things from the last ~72 hours worth your attention, sorted roughly by how much they should change what you do on Monday.

1. Anthropic's test agents filed a fake police tip and 20 visa applications

Anthropic self-disclosed that during evals a Claude Haiku 4.5 agent submitted an invented tip to a Philadelphia police form, and an unreleased research model filed 20 incomplete visa applications on a State Department site. Nobody was harmed, but "the instructions didn't rule out form submissions" is the whole lesson. Anthropic · Inquirer

Why it matters to you: deny-lists in prompts are not a security boundary. See today's deep dive.

2. Nadella: treat models like insider threats, build an "emergency brake"

Satya Nadella posted a manifesto: separate the model from its harness, externalize controls, log every meaningful action as tamper-proof human-readable evidence, and keep a human able to pause or kill a task mid-flight. That's basically an architecture spec. TechCrunch · Bloomberg

3. GPT-6 hits ChatGPT for everyone, with "Intelligent UI"

OpenAI rolled GPT-6 (Sol for paid, Luna for Free/Go) into ChatGPT chat, with answers that render interactive charts, forms and mini-tools inline. Note: Codex and Work models are not changing in this release. OpenAI

Why it matters to you: client expectations for "AI that builds a little tool on the spot" just reset. Generated UI is now table stakes for internal-tool pitches.

4. OpenAI trains agents on real vertical software — starting with Ironclad

OpenAI is partnering with software vendors to turn their hardest workflows into training/eval tasks; GPT-6 Astra scored 32% higher than GPT-5.6 Sol on Ironclad contract tasks at 48% less time per attempt. OpenAI

Why it matters to you: domain-specific evals are the moat. If you build for a vertical, own the eval set.

5. Atlassian puts GPT-6 behind Rovo, plus Codex/ChatGPT plugins for Jira context

Expanded deal brings GPT-6 Astra and GPT-5.6 into Rovo, and Teamwork Graph CLI plugins let Codex pull Jira/Confluence context with permissions. OpenAI

6. Claude Code 2.1.292–2.1.295: per-subagent effort and faster headless starts

The Agent tool now takes an effort parameter, claude -p/SDK sessions no longer block on remote MCP resources/list, and claude plugin install --marketplace lands. 2.1.295 fixes background-agent shutdown and adds a VS Code file row. Changelog · v2.1.295

Why it matters to you: run cheap low-effort subagents for grep/triage and save high effort for the actual change. Real token savings.

7. Codex CLI 0.162: managed worktrees and ranked tool discovery

TUI gets managed worktree tools, /copy for transcript blocks, and Code Mode gains ranked tool search plus streaming promise helpers. Release notes

8. Cursor CLI adds Opus 5.5 / Sonnet 5.5 on Bedrock

If a client is AWS-only, agent bedrock now gets you the latest Claude models via BYOK. Cursor CLI changelog

Why it matters to you: removes the "our data can't leave AWS" objection in consulting deals.

9. Cockroach Labs: 1,200+ production PRs from a "teaching hospital" of agents

Five months of treating bugs like patients and agents like a medical team — triage, specialists, review — with quality over raw speed; Db2 migration support shipped in under two days. Best real-world agent-ops writeup of the week. Cockroach Labs blog · HN discussion

10. Nvidia in talks to buy open-weights lab Reflection AI

FT reports Nvidia may acquire or deepen its stake in Reflection AI, the US open-model hopeful. Nvidia owning an open-weights lab would reshape the "self-host vs API" calculus. FT
