Thursday theme: rotate your keys. The AI-tooling supply chain had a rough day, and two of the first three items need action this morning. Eleven items, no deep dive.

1. LiteLLM 1.107.0 on PyPI shipped a credential stealer and backdoor

All seven 1.107.0 wheels drop three files into site-packages: cook.pth runs a stealer in every Python process on the host (even ones that never import litellm), and sitecustomize.py starts an hourly daemon that re-runs the stealer and downloads and runs remote code. It goes after SSH keys, cloud and CI/CD secrets, AI tool tokens, browser passwords, and the provider keys in a LiteLLM proxy database. PyPI pulled the release by 13:23 UTC Oct 21, but the Docker tags v1.107.0, latest, main-latest, and main-stable on Docker Hub and GHCR carried it between 11:46 and 14:20 UTC. Per LiteLLM's incident report, the attacker held three developers' GitHub CLI credentials (likely from logs of an internet-exposed internal deployment), bypassed branch protection with an org owner's token, and got the official pipeline to build, sign, and publish. 1.106.2 and the 1.107.0 release candidates are clean. SafeDep · LiteLLM incident report · HN

Why it matters to you: if any machine, CI runner, or container pulled 1.107.0 or a floating LiteLLM tag yesterday, treat it as compromised: rebuild it and rotate everything it could reach, starting with LLM provider keys. Signed artifacts didn't help here, so pin versions and add a cooldown before new releases reach agents and CI.

2. Railway: customer environment variables may have been decrypted

Railway says an unauthorized party accessed systems storing customer env vars and, for some, got the decrypted contents. It believes this is part of a series of attacks on platform companies aimed at compromising AI inference providers, and it has asked those providers to revoke keys proactively. Railway's advice to all users is to roll every env var and private registry credential now and check logs. All deployments are paused while it investigates. Railway · status · HN

Why it matters to you: following Tuesday's OpenCode Console breach, the pattern is attackers going after wherever AI keys pile up. If you or a client host on Railway, rotate today, and expect no deploys until builds resume.

3. GitLab critical patch release: upgrade self-managed now

GitLab shipped 19.5.1, 19.4.3, 19.3.6, 19.2.9, 19.1.9, 19.0.10, and 18.11.13 for CE and EE and says all self-managed installs should upgrade immediately. The critical fix is an integer overflow in the regular expression compiler. High-severity fixes cover OmniAuth-to-LDAP auto-linking authentication and cache poisoning on the OAuth/OIDC discovery endpoints. GitLab.com is already patched. GitLab · HN

Why it matters to you: self-hosted GitLab tends to be where client source code and CI secrets live. Put it on today's patch list.

4. The PHP fixes are out: 8.5.12, 8.4.27, 8.3.36, 8.2.35

Following yesterday's heads-up, the two critical RCEs are now patched. CVE-2026-109618: hitting memory_limit at the wrong moment corrupts memory, and on Apache with mod_php an unauthenticated request can trigger it before any app code runs; RCE was shown with default settings, and also on PHP-FPM through app-level code paths. CVE-2026-109619 is a use-after-free from stale state left by a fatal error, with RCE demonstrated on a real app on Apache mod_php. The PHP Foundation's post also explains how they were found and asks for funding from companies that depend on PHP. PHP Foundation · HN

Why it matters to you: if you lined up the upgrade yesterday, roll it now. Apache plus mod_php setups are the most exposed.

5. Linux kernel vulns posted to the public mailing list by mistake

Trend Micro's ZDI apparently sent several unpatched kernel vulnerability reports to the public LKML instead of the private security list. Two are rated CVSS 9.0 remote code execution: an SMB Direct integer underflow (patch queued in a branch for 7.5) and a KSMBD race condition. Others include local privilege escalations in skb_zerocopy and the VMware graphics driver. Mainline fixes aren't out yet. Phoronix

Why it matters to you: details are public before patches. If you run the in-kernel SMB server (ksmbd) anywhere, disable it or firewall it off until distro kernels ship fixes.

6. GitHub CLI can now use expiring, auto-refreshing tokens

From gh v2.103.0, gh auth login --expiring (or gh config set expiring_credentials enabled) stores a short-lived access token plus a rotating refresh token, so a leaked token stops working within hours. GitHub recommends gh auth setup-git and git 2.46+ so git doesn't cache the token past its lifetime. Opt-in public preview. Separately, GitHub's package firewall preview for Enterprise Cloud sits between agents/CI and upstream registries, with cooldown periods and malware advisory checks. GitHub (gh tokens) · GitHub (package firewall)

Why it matters to you: the LiteLLM attacker started with stolen gh CLI credentials. Turning this on takes one command, and it's an easy hardening step to add to every client engagement.

7. Claude Duet: Anthropic's proactive agent (research preview)

Duet briefs you every morning, drafts next steps, keeps working on tasks while you're away, and waits for approval before actions that matter. It's powered by Opus 5.5, uses your existing Claude memory, skills, and apps, and works with 6,000+ connectors and plugins. It's a waitlist for Pro and Max users in the US. Anthropic · HN

Why it matters to you: "an agent that runs the owner's morning" is a common custom build for small businesses. Expect clients to compare your quote against this, so focus on the integrations and approval rules Duet won't cover for them.

8. OpenAI models and Codex are coming to Google Cloud

OpenAI's frontier models and Codex agentic workflows will appear in Google Cloud's Model Garden, bought through Google Cloud Marketplace, and companies can count the spend against their existing GCP commitments. OpenAI models will also come to Google Antigravity and Gemini Agent. GA is planned in the coming weeks; OpenAI says Microsoft remains its primary cloud partner. OpenAI · HN

Why it matters to you: committed cloud spend is often what decides model choice at a client. A GCP shop can now use OpenAI models without a new vendor contract.

9. DuckDB 2.0 LTS ships an agent mode in the CLI

DuckDB 2.0.0 "Cinnamon Teal" is supported until at least October 2027 and brings a polished Quack client-server protocol, async I/O, a VARIANT type, triggers, and an extensible parser. The CLI now detects when a coding agent like Claude Code, Codex, or Cursor is driving it and switches to compact Markdown tables, says clearly when results were truncated, stops runaway queries early, reports errors as JSON, and shows the expected cost of long queries before running them. On TPC-H that cut the output the model had to read by 59%. Force it with -agent. DuckDB · HN

Why it matters to you: DuckDB is a great local analytics tool for agents, and fewer output tokens means cheaper, faster loops. Any CLI you build for agents should copy these ideas. Check the breaking changes before upgrading.

10. Recursive's Flint: a 40B/2.5B-active open coding model for laptops

Richard Socher's Recursive released Flint under Apache 2.0: a mixture-of-experts model with 39.8B total and about 2.5B active parameters, built largely with its automated "Eureka Machine" research system. In Recursive's tests it runs about 131 tokens/s on an M4 Pro MacBook Pro and 150+ on NVIDIA's RTX Spark. The company reports 74.2% SWE-bench Verified and 54.9% Terminal-Bench 2.1 (its own measurements, not yet reproduced by anyone else) and says to give it smaller subtasks. It's free on OpenRouter at launch. TechCrunch · Hugging Face · DigIntoAI (benchmarks)

Why it matters to you: a fast local model helps with clients whose code can't leave the building. Try it on routine subagent work (search, small edits, test fixes) before trusting the benchmarks.

11. Claude Code 2.1.307 logs every blocked tool call to OpenTelemetry

The new claude_code.safety_event OTEL event fires for each tool call that a permission rule, auto mode, a safety check, a hook, or the sandbox stopped, prompted, or sent back. The release also adds /claude-api api-version to move Claude API code to version 2026-10-21, and stops retrying non-idempotent HTTP MCP tool calls when a connection drops mid-call. GitHub release

Why it matters to you: together with last week's OTEL classifier fields, you can now show a client exactly what their agent fleet tried to do and what got blocked. That makes a ready-made audit dashboard.
