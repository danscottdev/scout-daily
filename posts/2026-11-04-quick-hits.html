Wednesday's theme: your coding agent's config is now attack surface, and so is the vendor sitting next to it. Postman wrote itself into people's Claude Code and Codex setups without asking. Codex users say the training opt-out turned itself back on. GitBook lost integration tokens to an attack it says was run by AI agents. Yesterday's weight-editing paper also got a useful reality check, Claude Code shipped another release, and Figma explained why it trained its own editing model. Ten items, no deep dive.

1. Postman installed plugins and a startup hook into your coding agents without asking

The top story on HN (1,300+ points) is a GitHub issue showing that Postman's desktop app, after an update, ran an auto-existing-upgrade step. That step installed a Postman plugin into Claude Code and Codex, installed the Postman CLI into ~/.local/bin, and pointed Codex at a remote MCP server (mcp.postman.com). Postman's own log shows it: "results":["claude-code:installed","codex:installed"]. The plugin registers a SessionStart hook that tells the agent to load Postman's api-engineer skill "before responding to any non-trivial API engineering task." The installer source also calls approvePostmanHook, which writes a trusted_hash into ~/.codex/config.toml so Codex treats the hook as already approved. A second user saw the same thing on 12.35.1 last night, with Cursor already wired up. Another found Postman enabled in ~/.copilot/settings.json, and says the in-app uninstall didn't remove it from Copilot. Postman replied in the thread last night (around 6:30 PM ET): the bundling was meant to make setup easier, it is mentioned on the download page, and it will "make the opt-in clearer, especially for existing users" and review the hook approval. Nobody in the thread claims data was exfiltrated. GitHub issue · HN

Why it matters to you: if Postman is on your machine, check ~/.claude/settings.json, ~/.claude/plugins/installed_plugins.json, ~/.codex/config.toml, and ~/.copilot/settings.json today. More broadly, any app running as your user can rewrite your agent's instructions, and a commenter in the thread showed that Codex's hook trust record is just a hash anyone can compute. For client fleets, put agent config directories under the same change monitoring you use for shell rc files, and push agent settings from managed policy.

2. Your "don't train on my data" setting may not have stayed off

A second HN thread (490 points) comes from a developer whose whole team had turned off "Improve the model for everyone" for Codex and found it switched back on. None of them say they opted back in. Several commenters report the same, including one whose settings history shows two earlier opt-out requests granted. Others say theirs is still off, so this isn't confirmed as widespread, and OpenAI hasn't commented in the thread. A separate Tell HN this morning points out that Google's own help pages say saved Gemini app chats on personal accounts, paid ones included, can be used to train models while "Keep Activity" is on. A subset is read by human reviewers and kept for up to three years even if you delete it, and the only opt-out is to turn chat history off (chats are then kept for 72 hours). Codex thread · ChatGPT data controls · Gemini thread · Google Gemini privacy hub

Why it matters to you: a toggle on a personal account is not a data agreement. If you're promising clients their code never trains anyone's model, use org or enterprise plans with contractual zero data retention, or route through Bedrock or Vertex, and check the setting again on a schedule. One commenter built a tool that flags agent accounts with training turned on (codealong). It's unvetted, but the idea is right.

3. GitBook breach: integration tokens and Git Sync secrets exposed, every API token revoked

GitBook says an attacker got some of its infrastructure credentials at 19:00 CET on November 2 (1 PM ET), in what it calls "a sophisticated, highly targeted attack using AI agents." GitBook took the app and authenticated docs sites offline, replaced every internal secret, and revoked all customer API tokens. It says the attacker may have accessed integration tokens, Git Sync secrets, API tokens, and questions visitors asked GitBook Assistant, and that it has found no sign content was changed. What customers need to do: rotate GitBook API tokens, rotate any third-party tokens connected to GitBook, rotate secrets used by published integrations, and re-authenticate the GitBook MCP server. As of this morning GitBook says the incident is resolved, though Git Sync is still affected by GitHub's outage (item 10), and a postmortem is promised within 24 hours. GitBook's CTO answered questions on HN. GitBook incident page · HN

Why it matters to you: this is another breach of a tool that holds tokens for other tools, after Trigger.dev and the "Black October" list. If a client's docs sync to GitHub through GitBook, the Git Sync credential is the one that matters most. Rotate it, and check the repo's audit log for the window since Nov 2.

4. Claude Code 2.1.318: login-expiry warnings for headless runs, cheaper mod side jobs

Today's release adds the date a stored claude.ai sign-in expires to claude auth status (loginExpiresAt) and to claude -p JSON output (credential_expires_at). Text-mode claude -p also prints a stderr warning starting 10 days before expiry. A mod's $.model.fork now takes an effort option, so a quick side job can run at low whatever the session's effort is. The Claude apps gateway gets assume_role on mantle upstreams, for cross-account AWS and per-developer AWS cost attribution. Behavior changes: Claude Code no longer installs or updates the IDE extension when started in an IDE terminal (worth noting after last week's fake-extension incident). deniedMcpServers URL entries now also block Anthropic-provided connectors whose upstream URL matches. Background subagents move a shell command to the background after 3 minutes on every provider, so the prompt cache doesn't expire while it runs. Self-hosted runner log lines changed format, which will break scripts that match retryable=true:. There are also 47 bug fixes, including --continue losing earlier conversation (a regression from 2.1.314) and claude -p reporting success when an API error cut off a reply. Claude Code changelog

Why it matters to you: if you run claude -p in CI or cron on a subscription login, alert on credential_expires_at now, before a job fails quietly at 2 AM. If you parse runner logs, update the regex before you upgrade.

5. Weight-space programming, day two: the pushback is worth reading

Yesterday's top item, MIT's "Sparks of Weight-Space Programming," got two strong responses. spaCy author Matthew Honnibal (about 1,000 points on HN) argues the post is misleading because it mixes two different techniques. The "just by looking at the raw weights" setting only appears in experiments on networks of 17K to 172K weights. Every experiment on a real language model, including the Qwen math fix, used Python, and the Qwen one could also run the model on up to 50 batches. His table also notes the from-scratch MinAtar networks beat PPO-500M only on Breakout. Simon Willison then ran the paper's no-tools "which game?" prompts on Qwen 3.8 27B on his laptop. It identified Pac-Man (72% confidence), Pong, and Breakout, taking 46 to 65 minutes and up to 43,506 reasoning tokens each, and got Freeway wrong. His view: a cool result, but "I expect a sufficiently experienced human being armed with a notepad and a pencil could get there." Honnibal · Willison · HN

Why it matters to you: the practical takeaway from yesterday still holds, but it's more ordinary than it sounded. The Qwen fix is a frontier model doing what an ML engineer does with a notebook: find a direction and subtract it. That's useful, but treat it like any interpretability-based edit and back it with a full eval suite.

6. Figma post-trained its own editing model, and it now does more of the agent's work

Figma's VP of Engineering Josh Clemm explains how its design agent handles small, repeated edits ("adjust the spacing," "insert this component top-left"). Early on, frontier models didn't understand Figma's format, and prompting them into it used too many tokens. So Figma did supervised fine-tuning on pairs of starting design, synthetic edit request, and successful change, using teacher models whose output was checked by deterministic validators and visual judges. An early Llama 3.3 70B trained on more than 250,000 examples was competitive with the top models of its time. Figma has since moved to newer bases, with its latest unreleased editing model post-trained on Qwen 3.8 27B, and added RL because SFT alone generalized poorly. The agent sends precise edits to its own model and image generation and new explorations to third-party models. Reported results: typical tasks are about 20% faster, users undo the agent's work 60% less often, the share of work on Figma's own model has more than doubled, and average cost per message is down. Figma blog

Why it matters to you: this is the playbook to pitch. Find the frequent, narrow, high-volume task in a client's product, generate synthetic pairs with a frontier teacher and automated validators, post-train an open ~27B model, and route by task. Most of the speed and cost gain comes from routing, not from beating the frontier model everywhere.

7. Google will switch off Search for K-12 students unless schools opt into AI

Google says Gemini, Gemini Notebook, Gemini in Classroom, and Google Search will be "entirely off" for K-12 student accounts until administrators turn them on. The change rolls out ahead of next year, with details to come. Google's education VP Chris Phillips told the NYT that "Search and AI are deeply integrated," so schools that reject AI entirely lose Search. After a backlash, which included Sen. Bernie Sanders calling it "extortion," Google said schools can enable Search alone without other Gemini products. Search will still include AI Overviews and AI Mode, now with "Guided Learning" walkthroughs that are being piloted in select US schools this month. Google blog · TechCrunch · NBC News

Why it matters to you: "AI is no longer a separate product you can turn off" is now an official position from the biggest search vendor. For regulated clients (education, health, government) that need search without generated summaries, a scoped search API plus your own retrieval layer is a real product, not a nice-to-have.

8. Namespace racks MacBooks so your agents can build iOS apps

Namespace CTO Kirill Nikolaev explains how the company runs macOS CI at scale, because "your coding agent needs a Mac" to build and test iOS. Mac Minis ordered in January arrived in July, so they racked MacBook Pros instead. Each needs an IP KVM, a 10G USB NIC, and four cables. The biggest headaches were HDMI cables, FileVault unlock prompts that expire after 5 minutes on laptops (tip: fdesetup authrestart), and USB NICs that drop until you recreate the network service. Apple's Virtualization framework allows only two macOS VMs per physical Mac, which is why instances come in halves (6/12 cores on 14-core Minis). Guest networking runs through gVisor's userspace TCP/IP stack and reaches about 4 Gbps. VM images of 500 GB or more are stored as sparse, layered OCI blobs, spread peer-to-peer across the fleet, and materialized with APFS holes and clonefile. Namespace blog · HN

Why it matters to you: if you're putting coding agents on a client's mobile codebase, the Mac is the bottleneck: a 2-VM limit per machine and Xcode betas that break stable Xcode. Plan agent concurrency around that, and steal the APFS sparse-file and cp -c tricks for local agent worktrees with big build caches.

9. Big Tech's off-balance-sheet AI commitments hit about $3.2 trillion

Nikkei's tally of Alphabet, Meta, Microsoft, Amazon, and Oracle puts AI-related off-balance-sheet commitments at about $3.2 trillion as of the end of September, up about 90% in six months. About 60% is purchase contracts for chips, servers, and power, and 40% is leases that haven't started yet. Together that's about 80% of the five companies' combined assets. Alphabet is the largest at about $1.05 trillion, though Nikkei notes its methodology appears to have changed, and Meta is around $810 billion. Businesskorea's summary of the Nikkei piece adds that Alphabet's free cash flow was negative by about $29 billion last quarter. Nikkei Asia · Businesskorea

Why it matters to you: put this next to yesterday's ~$895B in Anthropic commitments. Every layer of the stack has locked in huge compute bills that have to be paid back, which pushes toward price changes, usage-limit tweaks, and data-policy creep (see item 2). Keep client architectures portable across providers.
