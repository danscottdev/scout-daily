Sunday's theme is trust. A kernel bug that any TCP client can reach is still unpatched on the two most common server distros, a ChatGPT share link could take over your account, and Jepsen found 96 bugs in a database that looked mature on paper. On the build side, there's real data on which JS framework is cheapest for agents to build with, and DeepSeek open-sourced the routing layer for a team coding agent. Nine items, no deep dive.

1. CVE-2026-98432: a pre-auth Linux TCP bug, a Claude-built root exploit, and no Ubuntu or RHEL fix yet

A use-after-free in the IPv4 TCP handshake, rated CVSS 9.8, is reachable by any unauthenticated peer before your application ever sees the connection. It goes back to Linux 4.4. Upstream fixed it in mid-October (5.10.272, 5.15.223, 6.1.190, 6.6.159, 6.12.113, 6.18.56, 7.2.10, 7.3), and Debian, SUSE, Oracle UEK, and Amazon Linux have kernels. As of Oct 31 evening, Ubuntu still lists every release as vulnerable, and Red Hat, which raised it to Critical on Oct 30, has no fix for RHEL 8-10. AlmaLinux's fix is in testing. Anthropic, whose researcher reported it, says Claude wrote a remote root exploit for servers with a multipath TCP listener. The Go Security Team says Go 1.24+ programs open those listeners by default. The exploit hasn't been published. Atlas counted 36 GitHub repos referencing the CVE, at least six claiming a race trigger or PoC. Atlas writeup · HN

Why it matters to you: run ss -Mlnp on your servers and nodes to see which processes have multipath TCP listeners. Go 1.24+ services are the likely ones. Until your distro ships a kernel, set net.mptcp.enabled=0 (or GODEBUG=multipathtcp=0 for a single Go program) and drop IPv4 TCP packets carrying IP options; the writeup has the nft rule. Then reboot into the fix, because installing it isn't enough.

2. One ChatGPT share link could read your private chats

Parameter chained three harmless-looking features into an account takeover. A graph in a conversation loaded MathLive, which installed a postMessage listener on the main chatgpt.com page that accepted messages from any origin and rendered raw HTML. A sandboxed HTML Preview in the same shared conversation sent it markup for an unsandboxed iframe, and a YouTube JSONP endpoint allowed by ChatGPT's CSP got script running as chatgpt.com. From there it read the victim's private conversations through authenticated APIs and sent them out. In the best version, opening the link was the only click. It was reported Oct 18 and fixed Oct 26, with a $5,000 bounty that Simon Willison thinks was cheap for the severity. Parameter · Simon Willison · HN

Why it matters to you: if you build artifact or preview features for clients, the sandbox isn't the boundary. Every listener on the parent page is. Check both event.origin and event.source, never accept HTML over a message channel, and audit third-party libraries for listeners they install quietly.

3. Jepsen on ParticleDB: what an LLM-built database looks like under test

Jepsen found 96 issues in ParticleDB 1.1.4, Orkes' database for AI workloads, which was built with heavy LLM help. They include WHERE 4 = 5 returning a row, ignored NOT NULL and UNIQUE constraints, and committed writes lost in the default occ mode. Jepsen recommends halting deployments and migrating away. The report's LLM section is the part to read: the tooling "repeatedly claimed that bugs had been fixed when, in fact, they had not," and Orkes couldn't explain most fixes. Generative differential tests comparing ParticleDB's answers to Postgres found most of the bugs, and Jepsen argues example-based tests are still needed alongside them. Jepsen · HN

Why it matters to you: this is the risk your clients will ask about. The fix Jepsen points to is cheap and sellable: a differential test harness against a reference implementation, run before every release, plus example tests a human actually reads. Agents can write a lot of code fast, but you still have to prove it works.

4. Which JS framework is cheapest for an agent to build with? Someone measured it

Nolan Lawson had Opus 5.5 build the same Pokémon app five times per framework, with framework MCPs and skills available, graded against a conformance suite. Median cost ranged from $2.67 (Hono+htmx), $2.76 (Astro), $2.82 (Nuxt), and $2.98 (vanilla) through $3.14 (Next.js) to $4.28 (SvelteKit), $4.65 (Gracile+Lit), and $4.97 (Angular, which failed two of five runs). Hono+htmx came in at 1,370 lines versus Angular's 2,009, and Astro shipped 0 KiB of JS versus Next.js's 142 KiB. Agents often ignored the installed MCPs and skills, and he suspects some "may be doing more harm than good." Nolan Lawson · HN

Why it matters to you: less code means fewer tokens on every future edit, so stack choice now shows up on the bill. For content-heavy client sites, a server-rendered stack is cheaper to build and maintain with agents. And don't assume a framework's MCP is helping. Check whether your agent actually uses it.

5. ChatGPT and Codex will share one token-based usage pool from December

OpenAI's help center says Plus, Pro, and Business plans will share a single allowance across ChatGPT and Codex starting in December, measured in tokens, so heavier models and longer tasks use more. Instant chat won't count. Remaining usage will show in Settings, and you'll be able to buy credits when you run out. OpenAI Help · HN

Why it matters to you: if you or a client team uses Codex heavily on a Plus or Business seat, everyday ChatGPT use will now come out of the same allowance. Budget for it before December.

6. DeepSeek open-sources the routing layer for a team coding agent

dsh-superagent is an MIT-licensed "research prototype" for one GitHub repo. Built on DeepSeek Harness, it watches GitHub (Feishu is optional), turns each approved request into a ticket with its own worker session, keeps state in SQLite, replies with PRs, and gives you a web panel showing what needs a person. It picked up about 2K stars on day one. Note that workers run commands without approval as the operator's OS user, so sandbox it. GitHub · FourWeekMBA

Why it matters to you: the hard part of an "AI teammate" for a client isn't the coding. It's deciding what to act on, who's allowed to ask, and when to ping a human. This is a readable reference design for exactly that.

7. Claude Code 2.1.316: Opus 4.8 fast mode will start failing Nov 30

The release deprecates fast mode for Opus 4.8, with removal on Nov 30. After that, those requests error instead of falling back. It also adds pooled group budgets to the Claude apps gateway and a CLAUDE_CODE_SUBAGENT_EFFORT setting. Claude Code changelog · DeployedByAI

Why it matters to you: search your configs and CI for pinned Opus 4.8 fast mode now. CLAUDE_CODE_SUBAGENT_EFFORT is also an easy cost lever: run subagents at lower effort than the main loop.

8. Prospero: a lean, native coding harness built around "never wait forever"

Chris Wellons (nullprogram, w64devkit) built a C++/Dear ImGui harness that he says uses about two orders of magnitude fewer resources than typical web-stack harnesses. It brings your own endpoint (llama.cpp, OpenRouter, Anthropic or OpenAI API) and is configured with one INI file. Every operation has a deadline, and shell commands that time out become background jobs. Stopping a command kills its whole process tree, so you don't get stray builds. It also handles worktrees, MCP, desktop control, and headless engines over SSH. Claude subscriptions aren't supported. There's a free Community Edition and a paid Professional Edition with headless remote engines. nullprogram · HN

Why it matters to you: even if you never switch harnesses, those two rules (deadlines on everything and process-tree cleanup) fix the most common reasons an overnight agent run comes back with nothing done.

9. Anthropic's training-related safeguards are pushing heavy users toward a fallback model

A Hong Kong-based PhD researcher posted that Claude flagged his work as "training a competitor," and the HN thread (385 points) filled with similar stories of refusals on model training, kernel and firmware work, and security reviews. Several commenters point out that this was an Opus 5.5 safeguard interrupting a session, not an account ban, and that Hong Kong is a region where Anthropic blocks access anyway. Many others report "[cyber]" false positives. The consistent advice: keep a second model and harness you can switch to. HN thread

Why it matters to you: if a client's production workflow depends on one provider, sell the fallback as part of the build. That means a provider-agnostic harness, evals that run against two models, and a documented switch.
